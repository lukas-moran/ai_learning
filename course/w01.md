# Arrays as a Language for Data

A Python list holds objects. A NumPy array adds a contract: a dtype, a shape, and operations over axes. This chapter turns that contract into a habit that will prevent many silent machine-learning errors.

## Concepts

Treat every dimension as a named role. For a data matrix X with shape (n, d), rows are observations and columns are features. Reducing axis 0 leaves one value per feature; reducing axis 1 leaves one value per observation. A one-dimensional array with shape (d,) is neither an explicit row nor an explicit column. Reshaping it to (1, d) or (d, 1) makes the intended role visible.

Elementwise multiplication combines matching entries. Matrix multiplication sums over a shared inner dimension. Broadcasting instead compares dimensions from the right: dimensions must match or one must be 1; missing leading dimensions behave as 1. Broadcasting describes valid computation, not whether that computation expresses your intended model.

A dot product measures alignment as well as magnitude. For nonzero vectors, dividing it by their norms gives the cosine of the angle. A zero dot product implies orthogonality, but a zero vector has no defined direction. This distinction later matters when normalizing features or comparing embeddings.

## Detailed study

## Why an array needs more than a sequence of values

Imagine four patients and three measurements per patient. The same twelve numbers could represent a (4,3) table, a (3,4) table, or a one-dimensional sequence. Those interpretations imply different questions. In this route X has shape (n,d): n observations and d features. X[i,j] therefore means feature j of observation i. A shape ledger（形状记录表） records the role of each axis before computation.

An array also has a dtype. Integers store exact integers within a finite range; floating-point values approximate real numbers. Dividing an integer quantity may produce floating values, while assigning a float into an integer array can discard its fractional part. A computation is specified by values, shapes and types together. Inspect all three when an output seems plausible but differs from a hand calculation.

Indexing and slicing involve ownership as well as selection. Basic NumPy slices commonly produce views（视图） into shared storage, so changing the slice may change the original. Advanced integer or Boolean indexing creates a copy. Use an explicit copy when an independent working array is required, and test that requirement directly. The earlier Python reference model is useful, but NumPy storage adds its own rules.

## Derive broadcasting by fixing one output coordinate

To add a feature offset b of shape (d,) to X of shape (n,d), ask what output entry (i,j) should be: X[i,j]+b[j]. The offset does not depend on patient i. Broadcasting（广播） expresses that reuse without asking you to construct n copies of b. Compare dimensions from the right; each pair must match or contain a one. A dimension of length one supplies the same entry wherever the output coordinate varies along that axis.

Reduction removes an index. Summing X over axis 0 removes the patient index and leaves d feature totals. Summing over axis 1 removes the feature index and leaves n patient totals. Keeping reduced dimensions as length one can preserve the contract for a later broadcast. In contrast, a dot product contracts a shared index by multiplication and summation. Broadcasting addition performs no such contraction.

## The argument in mathematical notation

### Column standardization

$
\mu_j=\frac1n\sum_i X_{ij},\quad s_j^2=\frac1n\sum_i(X_{ij}-\mu_j)^2,\quad Z_{ij}=\frac{X_{ij}-\mu_j}{s_j}
$

## Translate a loop into vectorized code one index at a time

Consider squared distances between n observations and k candidate centers, each with d features. For a single pair, distance(i,j)=sum_r (X[i,r]-C[j,r])^2. There are two output indices, i and j, and one contracted feature index r. A direct broadcast can use shapes (n,1,d) and (1,k,d), giving differences of shape (n,k,d), then reduce the last axis. The output must be (n,k).

This is a correct mathematical translation, but its intermediate can be too large. Another identity uses squared norms and a matrix product: distance(i,j)=||X_i||^2+||C_j||^2-2 X_i dot C_j. That can avoid storing all n*k*d differences, although finite-precision cancellation can produce tiny negative results when vectors are extremely close. Do not replace numerical judgment with a blanket assertion that all algebraically equivalent code is equally stable.

For X=[[0,0],[1,2]] and C=[[0,1],[3,2]], the distance matrix is [[1,13],[2,4]]. Check each entry with the scalar formula, then compare the vectorized versions. The Handbook's array machinery now connects directly to K-means assignment in W13. The point of vectorization is expressing a verified index relation efficiently, not merely removing visible Python loops.

## Standardize two features by hand

1. Let X=[[1,10],[3,14],[5,18]]. Feature means are [3,14]. Subtract that row from every row to obtain [[-2,-4],[0,0],[2,4]]. The result still has shape (3,2).

2. Using population standard deviations, the two scales are sqrt(8/3) and sqrt(32/3). Dividing each centered column by its own scale makes their population variances equal to one.

3. The two standardized columns are identical. They differ originally only by a positive scale and offset. Standardization changes units; it does not manufacture independent information.

4. A constant column has scale zero. Choose an explicit policy, such as leaving its centered values at zero, and record that it is constant. Division by zero is not a meaningful standardized feature.

## Make a shape error fail before it changes the statistic

For n=3, subtracting a prediction column of shape (3,1) from a target vector of shape (3,) creates a (3,3) matrix. Its mean squared value is a real number, which makes the bug harder to notice than an exception. Assert that prediction and target shapes match before calculating a loss. Check semantic shape contracts even when broadcasting succeeds. The Handbook offers efficient array idioms; the statistical perspective explains why one residual per patient is required.

## Check a column standardization without external packages

```python
from math import sqrt

X = [[1., 10.], [3., 14.], [5., 18.]]
n, d = len(X), len(X[0])
means = [sum(row[j] for row in X) / n for j in range(d)]
scales = [sqrt(sum((row[j]-means[j])**2 for row in X)/n)
          for j in range(d)]
Z = [[(row[j]-means[j])/scales[j] for j in range(d)] for row in X]
for j in range(d):
    assert abs(sum(row[j] for row in Z)) < 1e-12
    assert abs(sum(row[j]**2 for row in Z)/n - 1) < 1e-12
assert all(abs(row[0]-row[1]) < 1e-12 for row in Z)
print(means, scales, Z)
```

## Further practice with worked solutions

### For shape (5,4), what is the shape of a row mean with dimensions retained?

Solution: (5,1). Each of five observations retains one mean. Subtracting it from the original centers each row; this is different from centering each feature.

### A standardized feature has mean zero. Does that make its values independent?

Solution: No. Centering and scaling constrain first and second moments of individual columns. Two columns can remain identical, as the worked example demonstrates.

## Worked example

1. Let A=[[1],[2],[3]] and B=[[10,20]]. Their shapes are (3,1) and (1,2), so A+B has shape (3,2).
2. The result is [[11,21],[12,22],[13,23]]. No summation occurs: entry (i,j) is A[i,0]+B[0,j].
3. For u=[1,2] and v=[3,4], elementwise multiplication gives [3,8], whereas the dot product is 11. The norm of u is sqrt(5).
4. If predictions have shape (3,1) and labels have shape (3,), subtraction produces (3,3), not three residuals. An operation can be valid and still be wrong.

## Comparing the sources

The Handbook teaches broadcasting as an efficient implementation rule; MML teaches vectors as mathematical objects. Connect them by declaring a row-batch convention before translating an equation. Neither convention is inherently superior, but mixing them silently is dangerous.

NumPy avoids explicitly tiling small operands in many broadcasts, but the result may still be large. Vectorized syntax does not guarantee a small memory footprint. Use current NumPy documentation to check dtype and view/copy behavior when adapting older Handbook examples.

## One-page recap

Name every axis, distinguish multiplication rules, and check both values and shapes. A successful operation is only a syntactic check; a meaningful result requires a data contract.

Matrix multiplication now becomes a map between spaces rather than a mysterious operator.

## Terms

- array (数组): A typed collection indexed along one or more axes.
- broadcasting (广播): Compatibility rules that extend size-one dimensions during elementwise operations.
- axis (轴): One indexed dimension of an array.
- dot product (内积): The sum of pairwise products of equally long vectors.
