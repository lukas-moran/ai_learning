Projection is a least-squares prediction（投影与最小二乘预测）

MIT develops projection from orthogonality（正交性）. ISLP introduces regression as a fitted relationship; CS229 differentiates a squared-error objective. These views meet at the same stationarity condition, but their interpretations answer different questions. Geometry identifies the closest available prediction. A probability model is needed for likelihood or uncertainty claims.

For y=[2,0] and v=[1,1], the available predictions are av=[a,a]. The squared discrepancy is (2-a)^2+a^2. Its derivative is 4a-4, so a=1. The residual y-av=[1,-1] has dot product zero with v. Expanding the loss around a=1 gives 2+2(a-1)^2, which establishes the minimum directly. If a matrix has redundant columns, several coefficients can generate the same projection; therefore compare fitted values as well as coefficients.

When using the video, stop after the geometric argument and reconstruct this example on paper. Then run the small least-squares program in the chapter. Do not spend the session proving the entire projection theorem. At PCA time, return to the same picture: projection onto a chosen direction is one problem; choosing that direction to capture variance is another.

Practice before revealing

Project y=[3,1] onto v=[1,1]. What are the coefficient, fitted vector and residual?

查看解析

The coefficient is (3+1)/(1+1)=2. The fitted vector is [2,2] and the residual is [1,-1]. The residual dot v is zero. Its squared length is 2. A coefficient of 3 would give residual [0,-2] and squared length 4.

Change the denominator, change the question（分母决定条件概率问题）

Seeing Theory makes events visible as regions of a sample space（样本空间）. Conditioning restricts attention to one region before taking a proportion. This supports a classifier decision more directly than memorizing a list of metric names. Recall conditions on actual positives; precision conditions on positive predictions. A change in the denominator changes which population a claim describes.

Consider 1000 cases, 100 actual positives, sensitivity 0.8 and false-positive rate 0.1. Expected counts are 80 true positives, 20 false negatives, 90 false positives and 810 true negatives under these rates. Positive predictions number 170, so precision is 80/170, about 0.471. Accuracy is 890/1000=0.89. High accuracy can coexist with many false alarms among positive predictions.

Now use a prevalence of 0.01 while retaining those conditional rates. Per 1000 cases, expected true positives are 8 and false positives are 99, so precision falls to 8/107, about 0.0748. This is a population thought experiment, not a claim that a fitted model keeps its detection rates under arbitrary deployment shifts. Use the interactive region view to name the conditioning event, then explain the confusion table without looking at formulas.

Practice before revealing

If prevalence is 0.2, sensitivity 0.8 and false-positive rate 0.1, what precision do the assumed rates imply?

查看解析

The positive joint probabilities are 0.2×0.8=0.16 and 0.8×0.1=0.08. Precision is 0.16/(0.16+0.08)=2/3. The denominator includes every predicted positive, not just actual positives.

Evaluate the procedure that will be fitted（评估完整拟合流程）

The scikit-learn MOOC complements ISLP resampling by making the fitting protocol executable. A cross-validation split is not simply a way to produce more scores. Each held-out fold stands in for new observations, so the complete fitted procedure must be learned from its training portion. This includes imputation, scaling, feature selection and the estimator.

Suppose training values for one feature are [0,2] and a held-out value is 100. The training mean is 1. The combined mean is 34. Using 34 to center the training values imports information from the held-out distribution. Even without labels, the fitted procedure has changed. A Pipeline（流水线） places transformation fitting inside each call to fit; cross-validation must receive the whole pipeline rather than already transformed full data.

For a split with training indices T and validation indices V, the intended order is transformer.fit(X[T]), transform both portions using that fitted transformer, estimator.fit on transformed T, then score V. Searching thresholds or hyperparameters adds selection, so do it inside development data. For final assessment, keep an outer test split untouched. Scores from overlapping training folds are dependent; their standard deviation is descriptive variability across those folds, not automatically a confidence interval for future performance.

Practice before revealing

Where should feature selection occur when choosing a model by cross-validation?

查看解析

Inside each training fold, as part of the pipeline being evaluated. Selecting features once using all labels before cross-validation allows held-out labels to influence the procedure. Hyperparameter selection also needs separation from final test assessment.

Read learning curves before adding complexity（先解释曲线，再增加复杂度）

Google’s overfitting lesson supplies a second visual explanation of the training/generalization distinction. Connect that picture to the ISLP bias–variance discussion and the training curves in your project. A model is not useful merely because it fits its training sample. The practical question is how a fixed fitting and selection procedure performs on the intended new cases.

Imagine validation losses at epochs 1–4 are [0.50,0.36,0.31,0.34], while training loss keeps falling. If the predeclared rule is minimum validation loss among saved checkpoints, select epoch 3. Do not choose epoch 4 because it is newest, and do not inspect test loss at every epoch to make the same decision. Early stopping（提前停止） is a selection rule; its choice belongs to development data.

The two curves alone do not prove that more regularization will solve the problem. Check label alignment, distribution differences, preprocessing and train/eval mode. Then change one factor under the same budget. In a one-hour session, one short baseline run and one justified comparison are enough. Keep all observed outcomes, including a failed comparison, rather than reporting only the most favorable run.

Practice before revealing

A test checkpoint at epoch 4 beats epoch 3, but epoch 3 has lower validation loss. May you use this test comparison to choose epoch 4?

查看解析

Doing so turns the test set into selection data. Follow the previously fixed validation rule, and reserve the test result for final assessment. If you already used test outcomes to choose, disclose that reuse and obtain independent assessment data when possible.
