The question

Concepts and derivation

Our momentum convention is v=beta*v+g, followed by w=w-eta*v. Other sources use v=beta*v+(1-beta)*g. These velocities differ by a scale, so equal numeric learning rates do not produce equal trajectories. State initialization and update order as well.

Adam keeps m=beta1*m+(1-beta1)*g and v=beta2*v+(1-beta2)*g^2, applies bias corrections for their zero initialization, then divides the first-moment estimate by the square root of the second plus epsilon. This adapts coordinate-wise step sizes; it does not guarantee better generalization（泛化）.

For ordinary SGD（随机梯度下降）, adding an L2 derivative can be written as coefficient shrinkage under matched conventions. With adaptive preconditioning, feeding the penalty into the gradient moments differs from decoupled weight decay（权重衰减）. Adam and AdamW therefore should not be described as identical algorithms with different names.

详细讲解 · 第 1 学习日

Momentum is an additional dynamical state

Plain SGD chooses an update from the current gradient. Momentum（动量） also retains an exponentially weighted history. One convention is v_t=beta*v_(t-1)+g_t followed by w_t=w_(t-1)-eta*v_t. Another uses (1-beta)*g_t. Those recurrences have different scale unless learning rates and initialization are adjusted. State the actual equation instead of comparing only an optimizer's name.

Momentum can reduce oscillation and build speed along a persistent direction. It can also carry a stale direction after the local gradient changes. Its behavior depends on curvature and the coefficient beta. Comparing a momentum run with plain SGD therefore requires a tuning and budget protocol, not the assumption that remembering gradients is always beneficial.

详细讲解 · 第 1 学习日

Adam rescales updates using estimated moments

Adam tracks a first-moment average m and a second raw-moment average v of the gradients. Starting those buffers at zero makes their early values biased toward zero. Bias correction divides them by 1-beta1^t and 1-beta2^t. A coordinate update uses corrected m divided by the square root of corrected v plus epsilon. The denominator is not an estimated variance（方差） unless the mean-square correction is handled separately; the standard v is a raw second moment.

Adding an L2 term to a loss puts its gradient inside this adaptive rescaling. AdamW instead decouples weight decay from the gradient-based step under its defined update. They need not yield the same trajectory. This extends W08's warning: an objective penalty, a prior（先验） interpretation and an optimizer operation agree only under the relevant definitions.

The argument in mathematical notation

Adam bias correction

\hat m_t=\frac{m_t}{1-\beta_1^t},\quad\hat v_t=\frac{v_t}{1-\beta_2^t},\quad w_t=w_{t-1}-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}

Track both moment recurrences and the step count. The displayed denominator uses epsilon outside the square root.

详细讲解 · 第 2 学习日

Use a constant-gradient calculation to understand momentum scale

For v_t=beta*v_(t-1)+g with constant g and v0=0, expand the recurrence into g*(1+beta+...+beta^(t-1)). The geometric sum is g*(1-beta^t)/(1-beta). With beta=0.9 the limiting velocity is 10g, so the same numeric learning rate（学习率） can eventually produce a step much larger than plain SGD.

For the normalized recurrence v_t=beta*v_(t-1)+(1-beta)*g, the velocity tends to g instead. The two conventions are related by a scale factor when initialized compatibly, but optimizer settings from one should not be copied blindly to the other. This explains an apparently surprising training curve without invoking vague claims that momentum "accelerates everything".

If the gradient changes sign, the old buffer must decay or be overcome. A large beta remembers longer. On a curved loss this can help travel along persistent directions or cause overshoot. The scalar recurrence is a mechanism demonstration; general performance still requires the controlled model experiment.

详细讲解 · 第 2 学习日

Compute the first two optimizer states

  1. For momentum v_t=0.9*v_(t-1)+g_t with v0=0 and gradients [2,2], the velocities are v1=2 and v2=3.8. At learning rate 0.1 the update magnitudes are 0.2 and 0.38.
  2. Using the normalized convention v_t=0.9*v_(t-1)+0.1*g_t instead yields 0.2 and 0.38 before multiplying by the learning rate. The same numeric learning rate no longer means the same step.
  3. For Adam's first gradient g=2 with beta1=0.9 and beta2=0.999, m1=0.2 and v1=0.004. Bias-corrected values are 2 and 4.
  4. Ignoring epsilon, the first Adam update is eta*2/sqrt(4)=eta. The initial gradient magnitude is largely normalized in this single-coordinate illustration; subsequent steps depend on the history.

Resume the optimizer as well as the parameters

When restoring a run, losing momentum or Adam buffers changes its future trajectory even if weights are identical. Record optimizer type, coefficients, epsilon, decay, learning-rate schedule and step count. Match the framework's precise equation, including where epsilon is placed. A learning rate tuned for one loss reduction or batch size is not automatically appropriate for another.

Inspect momentum conventions and Adam correction

from math import sqrt
beta = 0.9
velocity = 0.
velocities = []
for gradient in [2.,2.]:
    velocity = beta*velocity+gradient
    velocities.append(velocity)
assert abs(velocities[1]-3.8) < 1e-12
g, b1, b2 = 2., 0.9, 0.999
m, v = (1-b1)*g, (1-b2)*g*g
mhat, vhat = m/(1-b1), v/(1-b2)
assert abs(mhat-2) < 1e-12 and abs(vhat-4) < 1e-12
assert abs(mhat/sqrt(vhat)-1) < 1e-12
print(velocities, mhat, vhat)

详细讲解 · 第 4 学习日

Budget a fair optimizer comparison

Give each optimizer a stated tuning budget on development data. Compare several seeds with identical splits and report both updates and wall-clock time. One badly tuned learning rate cannot establish that an optimizer is inferior. Conversely, unlimited tuning for one method and one default run for another is an unequal search procedure.

Save trajectories, failures and best-validation checkpoints with their selection rule. Distinguish fastest training-loss decrease, best validation performance and lowest compute cost. D2L develops the update mechanisms while ISLP's selection perspective reminds us that the optimization comparison is itself an experiment subject to tuning bias.

详细讲解 · 第 5 学习日

Further practice with worked solutions

  1. Why is Adam v usually not called a gradient variance estimate?

    查看逐步解析

    It averages squared gradients, a raw second moment. Variance would subtract the squared mean under compatible estimators.

  2. Are Adam plus an L2 loss term and AdamW always equivalent?

    查看逐步解析

    No. Adaptive rescaling acts on the L2 gradient when it is coupled to the loss, while decoupled decay acts separately. Their parameter trajectories generally differ.

Worked example

  1. Let L=(w-2)^2, w0=0, eta=0.1, beta=0.8 and initial velocity zero. The first gradient is -4.
  2. Momentum gives v=-4 and w1=0.4. The next gradient is -3.2, so v=-6.4 and w2=1.04.
  3. Plain gradient descent has w1=0.4 and w2=0.72. Momentum moved farther, but farther is not automatically closer on every objective.
  4. For a first Adam step with g=-4 and standard zero-initialized moments, bias-corrected estimates are m_hat=-4 and v_hat=16. Ignoring epsilon, the step is +eta.

Comparing the sources

D2L explains optimizer mechanisms through controlled examples. PyTorch defines its exact optimizer conventions. CS229 supplies the gradient framework. Compare equations first, then run matched experiments; names alone are insufficient specifications.

An optimizer comparison must allow a declared tuning budget for learning rates. Reusing one optimizer-specific rate for every method can confound algorithm and configuration. Report updates, examples processed and elapsed time rather than relying on epochs alone.

import torch
from torch import nn
torch.set_num_threads(1)
torch.manual_seed(42)
X=torch.randn(120,2); y=(X[:,0]>X[:,1]).long()
for name in ["SGD","Adam"]:
    torch.manual_seed(7)
    model=nn.Sequential(nn.Linear(2,8),nn.ReLU(),nn.Linear(8,2))
    opt=getattr(torch.optim,name)(model.parameters(),lr=.03)
    curve=[]
    for step in range(80):
        opt.zero_grad(); loss=nn.functional.cross_entropy(model(X[:80]),y[:80])
        loss.backward(); opt.step(); curve.append(loss.item())
    model.eval()
    with torch.no_grad():
        accuracy=(model(X[80:]).argmax(1)==y[80:]).float().mean().item()
    print(name,"loss at 0/20/79:",[curve[i] for i in [0,20,79]],"validation:",accuracy)
# Same initialization/data/steps, not a claim of globally optimal hyperparameters.

One-page recap

An optimizer is an equation plus state and conventions, not just a class name.

momentum（动量）: An update method that carries a decaying history of gradients.

Adam（自适应矩估计）: An optimizer using bias-corrected moving averages of first and second gradient moments.

weight decay（权重衰减）: An explicit parameter shrinkage operation during optimization.

Training and evaluation behavior also change when regularization（正则化） layers enter the network.
