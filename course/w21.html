D, S and R denote data, split and random conditions; the comparison is not a universal causal claim.

Concepts and derivation

Choose a bounded question, such as whether standardization（标准化） improves a fixed optimizer under a declared budget. Identify the intervention, baseline（基线）, metric, data split and stopping rule. A protocol need not be publicly registered to be useful, but a timestamped plan makes later changes visible.

Rows can be disjoint while information still leaks through repeated users, near-duplicate images, future features or preprocessing. Define the independent unit and intended deployment setting. A forecasting task and a randomly sampled classification task need different evaluation logic.

A controlled software experiment supports conclusions within its fixed conditions. Changing optimizer, architecture and data simultaneously cannot isolate one cause. Even a clean comparison on one dataset does not establish universal superiority or real-world causal impact.

详细讲解 · 第 1 学习日

A research question needs a comparison and a scope

Replace "build a better classifier" with a claim that a finite experiment can address. For example: "With the same digit-image split and 500 parameter updates, does a small convolutional model reduce classification errors relative to a dense baseline?" This identifies the intervention, reference, outcome and budget. It does not claim that CNNs are universally superior or that an untested larger model would behave similarly.

Choose the data route to match the learning question. A house-price project emphasizes missing values, mixed tabular types and regression loss. Titanic emphasizes categorical preprocessing, class decisions and a small-sample evaluation. Digit images emphasize representation, architecture and visual error analysis. These are alternative settings for a controlled project, not a requirement to launch three more projects at once.

Write down your prediction time and unit, available variables, target, intended future population and primary metric. Distinguish a data split from a data version. The same random seed applied after rows have been reordered or filtered can produce a different split. Retain row identifiers or an explicit split manifest（划分清单） when reproducing results matters.

详细讲解 · 第 1 学习日

Match the split unit to the independence claim

Suppose a dataset has several photographs of each object. Randomly splitting photographs can put nearly identical views of one object in both development and test sets. That evaluates new views of familiar objects rather than recognition of unseen objects. Split by object identity if the latter is the goal. For repeated patient visits, split by patient; for forecasting, preserve time.

A final test set should simulate the use claim and remain untouched during model development. When data is small, cross-validation（交叉验证） may improve use of development observations, but it must retain the same group or time constraints. A balanced random fold cannot override the problem's dependence structure. Report known deviations rather than silently treating convenience as a scientific justification.

详细讲解 · 第 1 学习日

The argument in mathematical notation

State separation at the intended entity level

\{g_i:i\in\mathcal D_{\rm train}\}\cap\{g_i:i\in\mathcal D_{\rm test}\}=\varnothing

For generalization（泛化） to new groups, train and test group identities must be disjoint. This condition alone does not establish that all remaining assumptions hold.

详细讲解 · 第 4 学习日

Precommit the meaning of an improvement

Before final assessment, define a practically meaningful gain. A reduction from 10% to 9.9% error may be irrelevant if it doubles a constrained runtime; in another high-volume setting the same absolute reduction could matter. Specify the application context and constraints instead of using statistical detectability as the only definition of useful.

Write a short expected-results table with column names but no invented measurements: candidate, split, seed, primary loss, secondary metrics, latency and notes. Include an explicit untested state. A proposed run belongs in the plan; an executed run belongs in results. Keeping those categories visible prevents a teaching example or anticipated curve from becoming a falsely reported experiment.

Finally identify one plausible failure of your protocol: a historical split may not capture future policy changes, a random image split may retain near duplicates, or labels may have been collected selectively. The limitation（局限） should suggest a concrete next check. It need not paralyze the project, but it must limit the scope of the eventual claim.

详细讲解 · 第 2 学习日

Build a group-preserving development/test split

  1. Eight rows have group IDs [A,A,B,B,C,C,D,D]. A row-level split can place one row from each group in development and another in test, giving all four groups overlap.
  2. Choose development groups {A,B,C} and test group {D}. The resulting row counts are six and two, with no shared group identity.
  3. Calculate any group-derived feature（特征） using only legitimate information available in the intended use case. Removing the group-ID column does not remove duplicate observations or correlated information.
  4. With only one test group, conclusions about a broad group population are weak. The split fixes one kind of leakage（信息泄漏） but leaves a sample-size limitation. State both the protection and the remaining uncertainty（不确定性）.
详细讲解 · 第 3 学习日

Write a protocol before opening the final test results

Create a compact configuration containing the target, dataset version, split IDs, feature policy, preprocessing, primary metric, baseline, candidates, tuning budget and stopping rule. Add a claim you would make if the candidate wins and one you would make if it does not. This prevents rewriting the question after seeing an attractive number. A protocol can be revised during development, with revisions recorded before final testing.

详细讲解 · 第 3 学习日

Assert group separation using an explicit manifest

groups = ["A","A","B","B","C","C","D","D"]
train_groups = {"A","B","C"}
test_groups = {"D"}
train_ids = [i for i,g in enumerate(groups) if g in train_groups]
test_ids = [i for i,g in enumerate(groups) if g in test_groups]
assert set(train_ids).isdisjoint(test_ids)
assert {groups[i] for i in train_ids}.isdisjoint(
    {groups[i] for i in test_ids})
assert len(train_ids) == 6 and len(test_ids) == 2
assert sorted(train_ids+test_ids) == list(range(len(groups)))
print({"train":train_ids,"test":test_ids})

详细讲解 · 第 4 学习日

A data card is part of the experiment

Record provenance（来源与处理记录）, license, collection context, units, missingness（缺失机制） and known limitations. For a hosted dataset, retain its documented version or revision and any filtering commands. A leaderboard score may use a hidden distribution or metric different from your local objective（目标函数）. Treat it as a separate evaluation channel rather than repeatedly using it to tune unlimited variants.

The Handbook contributes the audit workflow, ISLP contributes the distinction between modeling and assessment, and CS229 contributes formal assumptions about learning. In this chapter those become a concrete experiment contract. The deliverable is a protocol another person could execute, not an ambitious list of architectures.

详细讲解 · 第 5 学习日

Further practice with worked solutions

  1. Why does dropping an entity ID not guarantee independence between train and test?

    查看逐步解析

    Other features, duplicated records and correlated measurements can still reveal the same entity. Split by identity where appropriate and inspect duplicates; removing a column alone does not alter dependence.

  2. What does one held-out group let you conclude?

    查看逐步解析

    It gives observed performance on that particular unseen group under the protocol. It offers limited information about variability across the wider group population and should be reported with that limitation.

Worked example

  1. Suppose A uses SGD（随机梯度下降） at rate 0.1 and B uses SGD at rate 0.01 with identical split, initialization and update budget. The declared change is learning rate（学习率）.
  2. If B also changes architecture and doubles epochs, the observed difference cannot be attributed to learning rate alone.
  3. If the final test result is used to select B, that test has become part of selection. A fresh evaluation is needed for an unselected estimate.
  4. A baseline need not be sophisticated: a simple model with a reproducible protocol is more informative than a complex model with an unclear comparison.

Comparing the sources

ISLP supplies the statistical evaluation logic, CS229 the model assumptions, and D2L/PyTorch the training machinery. The final project uses all three in one protocol instead of treating code execution as the endpoint.

Kaggle, AIcrowd and DrivenData provide tasks and datasets, not automatic scientific validity. Public leaderboard feedback is a repeatedly queried selection signal. Preserve a local validation design and obey data licenses and competition rules.

Implementation

Create config, split identifiers, dataset version, code revision and metric definitions before running variants.

Write a baseline command and a variant command that differ in one intended configuration field.

Declare a small budget suitable for the available hardware. Keep advanced models in a later extension rather than abandoning a reproducible baseline.

Five mastery checks

  1. What is the independent unit?

    查看参考答案

    The entity whose observations can reasonably be treated as separate for the evaluation question, often not simply a table row.

  2. Is row disjointness sufficient?

    查看参考答案

    No; duplicates, groups and time can transmit information.

  3. What does an ablation（消融实验） identify?

    查看参考答案

    The effect of the specified component change under the stated experimental conditions.

  4. Can a leaderboard select models without consequence?

    查看参考答案

    Repeated feedback creates selection pressure and can overfit that evaluation signal.

  5. What is the deliverable?

    查看参考答案

    A frozen protocol, baseline, metric, budget and explicit falsifying outcome.

One-page recap

Make the experiment answer one question clearly before making it larger.

ablation（消融实验）: A controlled comparison removing or changing a component.

preregistration（预注册）: Recording a protocol and hypotheses before inspecting the relevant outcomes.

external validity（外部有效性）: The extent to which a conclusion transfers beyond the evaluated setting.

The implementation must preserve the protocol through data loading, training and checkpointing.
