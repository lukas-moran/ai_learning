Concepts and derivation

A typical training iteration clears old gradients, computes a forward loss, calls backward, and steps the optimizer. Backward accumulates into parameter gradient buffers. Forgetting to clear them changes the update rule; deliberate accumulation is valid only when loss scaling and update frequency are planned.

model.eval() changes behaviors such as dropout（随机失活） and batch normalization（批量归一化）. A no_grad context disables graph recording; it does not switch the model mode. Use both for conventional evaluation. Restoring train mode before the next training phase is a separate responsibility.

Integer class labels and raw logits（类别分数） belong with CrossEntropyLoss. Supplying probabilities adds an unintended normalization（归一化） and changes the calculation. Check dtype（数据类型）, device and reduction settings. A framework loss is a precise API contract, not a generic operation called classification.

详细讲解 · 第 1 学习日

Autograd records operations, not your intended mathematics

Automatic differentiation（自动微分） builds derivative computations from the operations actually executed. If a broadcast or reduction is wrong, autograd can correctly differentiate that wrong function（函数）. This is why the shape（形状） and forward-value checks from earlier chapters remain essential. Automatic derivatives remove manual chain-rule bookkeeping; they do not validate labels, targets, data availability or the evaluation design.

In PyTorch, tensors carrying parameters usually require gradients. A backward call accumulates contributions into gradient buffers. An optimizer step uses those buffers to change parameters. Zeroing gradients, building the forward graph, calculating loss, calling backward and stepping the optimizer are distinct operations. Rearranging them without understanding their state can silently train a different procedure.

Model evaluation mode and gradient recording are separate controls. eval() changes modules such as dropout and batch normalization. no_grad() disables recording of derivative graphs. Evaluation commonly uses both, but calling one does not imply the other. Parameters do not stop existing or become frozen merely because evaluation mode is enabled.

详细讲解 · 第 1 学习日

Reproduce one update before reproducing an entire training run

Translate a single affine（仿射） layer by copying known weights and biases. In the course's row-batch convention, W has shape (in,out). PyTorch Linear stores weight with shape (out,in). Copy（副本） its transpose, align dtype and compare outputs before attaching a loss. Then compare the loss, every gradient and one optimizer update. These checkpoints distinguish a translation error from a later training difference.

Use a simple optimizer such as plain SGD（随机梯度下降） without momentum（动量） for the first update check. Momentum and adaptive optimizers carry additional state. Matching only parameter values at initialization is not enough to reproduce a later update when optimizer buffers differ. Saving a checkpoint（检查点） for continuation generally requires model state, optimizer state and enough configuration to reconstruct the run.

详细讲解 · 第 1 学习日

The argument in mathematical notation

Correctly weight accumulated micro-batch means

L=\frac{\sum_b n_b L_b}{\sum_b n_b},\qquad \nabla L=\sum_b\frac{n_b}{\sum_r n_r}\nabla L_b

This applies when L_b is the mean loss over n_b observations. Other masks and weights can require a different denominator.

详细讲解 · 第 3 学习日

Understand what detaching a tensor changes in the graph

Detaching an intermediate value treats it as a constant for later derivative propagation. It does not generally create independently owned storage. If a loss depends on both z and a detached copy of z, the numeric forward values may be identical while derivative paths differ. This is useful for deliberate gradient blocking but dangerous when inserted just to make an error disappear.

For z=w^2 and L=z+stop_gradient(z), the forward value is 2w^2 but the derivative traced by the specified graph is 2w, not 4w. A finite difference（有限差分） of a plain numerical function 2w^2 differentiates a different object because it does not implement the same stop-gradient semantics. Explain which computational function is being differentiated before interpreting a mismatch.

A clone, a detach operation and a conversion to an ordinary number solve different problems: storage ownership, gradient connectivity and leaving tensor computation. Consult the framework's contract and keep the operation deliberate. The manual graph model from W16 is the most reliable guide when these operations become confusing.

详细讲解 · 第 2 学习日

See gradient accumulation numerically

  1. Let L(w)=(2w-3)^2 at w=1. The derivative is 4(2w-3)=-4. A gradient buffer initially zero becomes -4 after one contribution.
  2. A second backward contribution from the same loss adds another -4, making the buffer -8 unless it was cleared. It does not replace the first value.
  3. An SGD step with eta=0.1 would move w from 1 to 1.4 using -4, but to 1.8 using -8. Both are legal updates; only one matches the intended single-loss step.
  4. If accumulating micro-batches deliberately, scale their losses to represent the desired full-batch mean. Unequal micro-batch sizes require observation-weighted contributions rather than blindly averaging batch means.
详细讲解 · 第 3 学习日

Treat a training loop as a state machine

At each update, know which parameters, gradient buffers, data batch and optimizer buffers are current. Keep training and validation data paths distinct. During validation, avoid optimizer steps and aggregate metrics with the right denominator. For classification, pass raw logits to CrossEntropyLoss under its documented contract. Reconstruct the model before loading weights, and verify a fixed input's predictions after loading.

详细讲解 · 第 3 学习日

Simulate accumulated gradients without a framework

w, eta = 1., 0.1
def derivative(value):
    return 4*(2*value-3)

gradient_buffer = 0.
gradient_buffer += derivative(w)
single_update = w-eta*gradient_buffer
gradient_buffer += derivative(w)
double_update = w-eta*gradient_buffer
assert gradient_buffer == -8
assert abs(single_update-1.4) < 1e-12
assert abs(double_update-1.8) < 1e-12
print(single_update, double_update)

详细讲解 · 第 4 学习日

Separate a parity experiment from a performance experiment

For parity, use the same tiny data, fixed parameters, CPU, dtype, operation order and loss reduction. Compare within a justified tolerance. For performance, train a realistic model and report its protocol and variability. Exact bitwise agreement may not persist across devices or kernels even when the algorithms are mathematically equivalent. A seed is part of reproducibility（可复现性）, not a universal determinism switch.

The framework tutorials are the authority for API behavior, D2L explains the training pattern, and the hand-derived network establishes what function should be implemented. Keep all three visible in the comparison report rather than replacing mathematical reasoning with a successful backward call.

详细讲解 · 第 5 学习日

Further practice with worked solutions

  1. Can autograd certify that your target vector has the right shape?

    查看逐步解析

    No. A wrong shape can broadcast into a valid but unintended loss that autograd differentiates correctly. Assert the contract before computing the loss.

  2. What additional state can be needed to resume Adam（自适应矩估计） faithfully?

    查看逐步解析

    Moment estimates, step counters, parameter-group settings and other optimizer state, in addition to model weights. Data order, scheduler and random state can matter for reproducing the full continuation.

Worked example

  1. For scalar x=3 and loss x^2, one backward pass contributes gradient 6.
  2. Rebuild the same forward graph at fixed x and call backward again without clearing: the buffer becomes 12.
  3. Clear before each pass and it remains 6. If an optimizer changes x, the contributions are evaluated at different parameter values.
  4. For a NumPy layer with W shaped (d,h), copy W-transpose into a PyTorch Linear weight before comparing forward outputs.

Comparing the sources

D2L builds training loops in a pedagogical progression. PyTorch tutorials define the supported API behavior. CS229 supplies the chain-rule reasoning that explains the resulting gradients. Use all three to distinguish conceptual mistakes from API misuse.

A matching forward pass is necessary but insufficient. Also compare loss reduction and parameter gradients. Framework defaults such as dtype or initialization can make otherwise equivalent-looking experiments differ.

Implementation

Start with one batch and identical NumPy/PyTorch weights. Compare outputs, loss and gradients before long training.

Make training and evaluation functions separate, with explicit mode changes. Weight aggregate losses by the number of observations.

Save state_dict plus model configuration and preprocessing information. A weight file alone may not identify the inference（统计推断） procedure.

import numpy as np
import torch
torch.set_num_threads(1)
rng=np.random.default_rng(7)
X=rng.normal(size=(4,2)); y=np.array([0,1,1,0])
params=[rng.normal(size=(2,3))*.2,np.array([.7,.9,1.1]),rng.normal(size=(3,2))*.2,np.zeros(2)]
W1,b1,W2,b2=params
A=X@W1+b1; H=np.maximum(0,A); Z=H@W2+b2
shift=Z-Z.max(1,keepdims=True); logp=shift-np.log(np.exp(shift).sum(1,keepdims=True))
loss=-logp[np.arange(4),y].mean()
dZ=np.exp(logp); dZ[np.arange(4),y]-=1; dZ/=4
dA=(dZ@W2.T)*(A>0)
np_grads=[X.T@dA,dA.sum(0),H.T@dZ,dZ.sum(0)]
tp=[torch.tensor(v,dtype=torch.float64,requires_grad=True) for v in params]
tx=torch.tensor(X,dtype=torch.float64)
logits=torch.relu(tx@tp[0]+tp[1])@tp[2]+tp[3]
tloss=torch.nn.functional.cross_entropy(logits,torch.tensor(y,dtype=torch.long))
tloss.backward()
assert np.isclose(loss,tloss.item())
for param,expected in zip(tp,np_grads):
    assert np.allclose(param.grad.numpy(),expected,atol=1e-10)
print("NumPy/PyTorch loss and all gradients agree:",loss)
x=torch.tensor(3.,requires_grad=True)
(x*x).backward(); print("first:",x.grad.item())
(x*x).backward(); print("accumulated:",x.grad.item())
x.grad=None

One-page recap

Automation is trustworthy when you know which responsibilities remain outside it.

autograd（自动微分）: Automatic derivative computation through recorded operations.

leaf tensor（叶子张量）: A tensor at a graph boundary, often a trainable parameter whose gradient is retained.

gradient accumulation（梯度累积）: Adding successive backward contributions into gradient buffers.

Convolution（卷积） changes the layer structure while retaining the same derivative and training rules.
