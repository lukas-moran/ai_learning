Concepts and derivation

Gradient descent updates parameters using the current gradient. For a smooth objective, a sufficiently small step along a nonzero negative gradient decreases the loss locally. This does not imply that one fixed step size works for every dataset or every stage of training. Curvature and feature（特征） scale control the useful range.

Optimization error is distance from the chosen training objective optimum; generalization（泛化） error concerns unseen data. An undertrained model can have high training and validation error. An overfit model may have low training error and poor validation performance. A flat curve could also reflect a bug, so inspect updates and gradient values.

Batch gradients use all training observations per step. Mini-batch（小批量） gradients add sampling variability and change how many updates fit in an epoch（训练轮次）. Compare runs by both examples processed and update count; equal epochs do not guarantee equal computational effort.

详细讲解 · 第 1 学习日

A gradient is a local model of the objective

For a differentiable loss, a small displacement delta changes the loss approximately by gradient dot delta. Choosing delta=-eta times gradient makes the first-order change -eta times the squared gradient norm, negative for a nonzero gradient and eta>0. This explains descent locally. The omitted curvature term explains why a large step can increase the loss.

For a quadratic loss, curvature is encoded by the Hessian（海森矩阵）. Different directions can have very different curvature. In a narrow valley, one learning rate must be small enough for the steep direction, making progress along a shallow direction slow. Standardizing features can help with this geometry, but it cannot remove exact feature redundancy. The optimization problem, coordinate choice and update rule interact.

详细讲解 · 第 1 学习日

Distinguish three reasons for an unsatisfactory curve

Optimization error means the algorithm has not yet minimized its training objective. Statistical estimation error concerns the difference between a sample fit and the population relationship. Model approximation error concerns restrictions of the chosen function（函数） class. More iterations address the first, not necessarily the others. A wrong gradient is a separate implementation error and should be tested before interpreting a curve.

Mini-batch updates average contributions from a subset of observations. Their noise depends on sampling and batch size. Equal epochs do not imply equal numbers of updates: 1000 observations with batch size 10 give about 100 updates per epoch, while batch size 100 gives about 10. Compare both data passes and computational budgets when making optimization claims.

详细讲解 · 第 1 学习日

The argument in mathematical notation

Curvature controls a scalar stability interval

L(w)=\frac a2(w-w_*)^2,\quad e_{t+1}=(1-\eta a)e_t,\quad 0<\eta<\frac2a

For positive a, the error contracts from a nonoptimal initial value exactly when the multiplier has magnitude below one.

详细讲解 · 第 3 学习日

Translate per-observation gradients into batch and stochastic updates

For one squared-loss contribution ell_i=(x_i*w+b-y_i)^2, define g_i as its parameter gradient. The full mean gradient is the average of all g_i values. Sampling an observation uniformly makes its gradient an unbiased estimator of that full gradient when evaluated at the same fixed parameter state. After each stochastic update the parameter changes, so a sequence of stochastic updates is not identical to one update using the average of old gradients.

For losses (w-1)^2 and (w-3)^2 at w=0, the individual derivatives are -2 and -6; their mean is -4. A full-mean step with eta=0.1 gives w=0.4. Sequential steps give w=0.2 after the first loss, then 0.76 after the second because its derivative is evaluated at 0.2. Reversing their order gives another trajectory.

This explains why batch size, order and learning-rate conventions belong in a reproducible report. It also shows why equal epochs alone do not align optimization. D2L's minibatch treatment and CS229's stochastic LMS updates complement the deterministic stability calculation rather than contradicting it.

详细讲解 · 第 2 学习日

Obtain the stability interval from the actual curvature

  1. Consider L(w)=2(w-3)^2. The derivative is 4(w-3), and the update is w_next=w-4*eta*(w-3).
  2. Define the error e=w-3. Then e_next=(1-4*eta)e. Convergence from a nonoptimal start requires |1-4*eta|<1, so 0<eta<1/2.
  3. At eta=0.1 and w0=0, the first values are 0,1.2,1.92,2.352. The error shrinks by factor 0.6 each step.
  4. At eta=0.5 the factor is -1 and values alternate between 0 and 6. At eta=0.6 the factor is -1.4 and errors grow while changing sign. This differs from the threshold for L=(w-3)^2 because the curvature doubled.
详细讲解 · 第 3 学习日

Use traceable stopping rules and logs

Store the loss with its matching parameter state. A common plotting error records the loss before the update but labels it with the post-update parameters. Choose a maximum update budget plus a criterion such as a small gradient norm or a small relative loss change. A tiny parameter update can mean either convergence or an excessively small learning rate. Inspect the gradient as well.

详细讲解 · 第 3 学习日

Compare stable, oscillating and divergent steps

def trajectory(eta, steps=6):
    w = 0.
    values = [w]
    for _ in range(steps):
        w -= eta * 4 * (w-3)
        values.append(w)
    return values

stable = trajectory(0.1)
assert abs(stable[1]-1.2) < 1e-12
assert abs(stable[2]-1.92) < 1e-12
assert trajectory(0.5, 2) == [0., 6., 0.]
assert abs(trajectory(0.6)[-1]-3) > 3
print(stable, trajectory(0.5), trajectory(0.6))

详细讲解 · 第 4 学习日

Turn project one into a reasoned comparison

Use one fixed dataset and split for three learning rates. Keep initialization, preprocessing and update budget fixed. Predict which run should fail before execution, then show the full training-loss trajectory. Separately compare held-out MSE（均方误差） against the training-mean baseline（基线） and a library least-squares model. A solver can reach the training optimum while yielding a disappointing predictive result.

Your report should identify what each comparison can establish. Numerical derivative agreement supports the local gradient implementation. Agreement with a least-squares reference supports the fitted objective. Held-out improvement supports predictive usefulness under the chosen protocol. None of these alone proves robust performance across new populations. This is the point where the code-centered and statistics-centered resources become one experimental workflow.

详细讲解 · 第 5 学习日

Further practice with worked solutions

  1. Why can two implementations with identical minima need different learning rates?

    查看逐步解析

    Their objective scaling or parameterization can produce different gradient magnitudes and curvature. Compare the full objective and update, not only the optimum.

  2. Training and validation losses are both high. Is the model necessarily too simple?

    查看逐步解析

    No. Check undertraining, feature scale, incorrect preprocessing and implementation errors before attributing the result to approximation limits. Compare against a reliably optimized reference.

Worked example

  1. For L(w)=(w-3)^2, gradient descent gives w_next=w-2 eta(w-3).
  2. Subtract 3 from both sides: error_next=(1-2 eta)error. Thus this example converges from w0=0 when 0<eta<1.
  3. At eta=0.25, the sequence begins 0,1.5,2.25,2.625. At eta=1 it alternates 0,6,0,6.
  4. This threshold belongs to this specific curvature. Rescaling the loss or the feature changes the safe range.

Comparing the sources

CS229 presents LMS and stochastic updates; D2L connects optimization to minibatches and generalization. ISLP mainly evaluates the fitted procedure. Use optimization curves to diagnose the solver, then held-out metrics to judge the model.

A scikit-learn least-squares fit is a useful target for the unregularized training objective, but it need not use gradient descent. Matching predictions validates the endpoint, not your optimizer trajectory or its speed.

Implementation

Log loss before and after updates consistently. Set a maximum iteration budget and a stated stopping rule.

Keep split, initialization and preprocessing fixed when comparing learning rates. Save the full curve rather than only the last loss.

Compare your NumPy predictor, the training-mean baseline and a library regression under one protocol. A failed improvement is still reportable if explained.

import numpy as np
rng = np.random.default_rng(42)
X = rng.normal(size=(120, 2))
y = X @ np.array([2., -1.]) + .5 + rng.normal(0, .1, 120)
Xtr, Xv, ytr, yv = X[:80], X[80:], y[:80], y[80:]
for lr in [.001, .1, 1.2]:
    w, b = np.zeros(2), 0.
    history = []
    for _ in range(100):
        error = Xtr @ w + b - ytr
        history.append(np.mean(error**2))
        w -= lr * 2 * Xtr.T @ error / len(ytr)
        b -= lr * 2 * error.mean()
    print("lr, first/last training loss, validation MSE:", lr,
          history[0], history[-1], np.mean((Xv @ w + b - yv)**2))
design = np.column_stack([Xtr, np.ones(len(Xtr))])
solution = np.linalg.lstsq(design, ytr, rcond=None)[0]
print("least-squares validation:", np.mean((Xv @ solution[:-1] + solution[-1] - yv)**2))
print("mean baseline:", np.mean((ytr.mean() - yv)**2))
# Optional library comparison, using the same unregularized objective.
try:
    from sklearn.linear_model import LinearRegression
except ImportError:
    print("Install scikit-learn to run the library comparison.")
else:
    model = LinearRegression().fit(Xtr, ytr)
    assert np.allclose(model.coef_, solution[:-1])
    assert np.allclose(model.intercept_, solution[-1])

Five mastery checks

  1. Does a falling training loss prove useful prediction?

  2. What happens at eta=0 in the example?

    查看参考答案

    No update; w remains 0.

  3. Why can standardization（标准化） help gradient descent?

    查看参考答案

    It can reduce severe curvature differences between feature directions, though it does not guarantee perfect conditioning.

  4. Why record update counts?

    查看参考答案

    Batch size changes the number and noise of updates per epoch.

One-page recap

Report what the optimizer did and what the model predicts as separate pieces of evidence.

learning rate（学习率）: The scale multiplying an update direction.

convergence（收敛）: Approach of a sequence to a limiting value under stated conditions.

stochastic gradient（随机梯度）: A gradient estimate formed from sampled observations or batches.

For classification, the output and loss must change together.
