# Trees and Ensembles: Local Rules, Shared Evidence

A linear model adds global feature contributions. A decision tree partitions the feature space into regions and fits a simple prediction inside each region.

## Concepts

A binary split sends each observation left or right using a feature threshold. For classification, choose a split that reduces sample-weighted child impurity. A pure node has Gini zero. Depth permits increasingly specific partitions and can fit noise, especially when leaves contain very few observations.

A tree is often sensitive to small changes in training data. Bagging averages or votes across bootstrap-trained trees to reduce variability. Random forests also restrict candidate features at splits, encouraging trees to differ. Averaging highly correlated predictions yields less variance reduction than averaging less-correlated predictions.

Boosting adds learners sequentially to correct a current ensemble according to a loss. It is not simply a synonym for more bagged trees. This chapter requires a shallow tree and a forest; boosting is a mapped extension once validation and tuning budgets are under control.

## Detailed study

## A decision tree converts a global problem into local questions

A regression tree partitions predictor space and predicts a constant within each leaf. For squared loss, that constant is the training-target mean in the leaf. A classification tree stores class counts or proportions and can choose a class from them. A threshold split such as x_j<=t asks whether two child regions provide a better fit than the parent. Splitting is a local, greedy choice, so the first apparently best split need not belong to a globally optimal tree.

For classification, Gini impurity（基尼不纯度） is 1 minus the sum of squared class proportions. It is zero in a pure node. A split is judged by the size-weighted impurity of its children, not by adding child impurities without regard to sample count. For regression, use within-child squared residual sums. The split criterion must match the type of target and the implementation.

## Why averaging trees can reduce variance

A deep tree can change sharply when a few observations change. Bagging（装袋法） fits trees to bootstrap samples and averages predictions. If M estimates have equal variance sigma squared and pairwise correlation rho, the variance of their average is sigma squared times [rho+(1-rho)/M]. More trees remove the independent part but not the shared correlated component.

Random forests introduce feature subsampling to make trees less correlated, often trading a little individual-tree strength for a better ensemble. This is different from boosting（提升法）, where sequential learners focus on improving a combined objective. Do not describe all ensembles as interchangeable voting schemes. ISLP explains the statistical tradeoffs; the Handbook gives a practical model interface. Neither removes the need for a leakage-free comparison.

## The argument in mathematical notation

### Variance reduction depends on correlation

$
\operatorname{Var}\!\left(\frac1M\sum_{m=1}^{M}T_m\right)=\sigma^2\left(\rho+\frac{1-\rho}{M}\right)
$

This illustration assumes equal variance and common pairwise correlation. Expand the variance into M variance terms and M(M-1) covariance terms.

## A classification split requires both child rates and counts

A parent node has eight observations, four from each of two classes, so Gini impurity is 0.5. Split it into a left node with three positives and one negative, and a right node with one positive and three negatives. Each child has impurity 1-(3/4)^2-(1/4)^2=0.375. Weighted child impurity is 0.375 and the improvement is 0.125.

Compare a split with one pure positive on the left and the remaining three positives plus four negatives on the right. The large child's impurity is 24/49; weighted by 7/8 it contributes 3/7, approximately 0.4286. The weighted improvement is only about 0.0714. Taking the unweighted mean of child impurities would reward the tiny pure child too strongly.

This example connects local probability estimates to the algorithm's selection criterion. Tree class proportions are also affected by small leaf counts; a leaf with one positive observation can report a probability of one without providing strong evidence of certainty. Limit leaf size and assess probability quality separately from class accuracy.

## Choose a regression split using actual squared errors

1. Take sorted feature values [1,2,3,4] and targets [1,1,5,5]. The parent mean is 3 and its SSE is 16.

2. Split at 2.5. The left child predicts 1 and the right child predicts 5. Both child SSE values are zero, so the training SSE improvement is 16.

3. Split at 1.5 instead. The left child is pure. The right targets [1,5,5] have mean 11/3 and SSE=32/3, approximately 10.667. This split is less effective on the fitting sample.

4. A threshold separating observed groups does not describe reliable extrapolation. For x=100, an ordinary regression tree still predicts the constant in its far-right leaf, rather than extending a fitted slope.

## Make split calculations auditable before fitting a forest

Compute one split by hand and then reproduce it with a tiny program. Check candidate thresholds between distinct sorted feature values. Record minimum leaf size and depth constraints before fitting. If a library uses sample weights, missing-value routing or another criterion, align those details before expecting an exact match. Your small calculation tests a mechanism, not a replacement production tree engine.

## Compare candidate splits without a tree dependency

```python
def sse(values):
    mean = sum(values)/len(values)
    return sum((x-mean)**2 for x in values)

x, y = [1,2,3,4], [1.,1.,5.,5.]
scores = {}
for cut in [1.5, 2.5, 3.5]:
    left = [b for a,b in zip(x,y) if a <= cut]
    right = [b for a,b in zip(x,y) if a > cut]
    scores[cut] = sse(left)+sse(right)
assert min(scores, key=scores.get) == 2.5
assert scores[2.5] == 0
assert abs(scores[1.5]-32/3) < 1e-12
print(scores)
```

## Further practice with worked solutions

### Why weight child impurities by child size?

Solution: The objective concerns observations, not an equal vote from each region. A small pure child should not conceal a large mixed child.

### Will infinitely many correlated trees remove all prediction variance?

Solution: No. Under the equal-variance illustration, the variance limit is rho*sigma squared. Averaging cannot eliminate variation shared by all trees.

## Worked example

1. Eight ordered labels are [0,0,0,1,0,1,1,1]. The parent has four of each class, so Gini=0.5.
2. A split after the third observation gives a pure left node and a right node with proportions 1/5 and 4/5. Right Gini=0.32.
3. Weighted child impurity is (3/8)*0+(5/8)*0.32=0.20, hence gain=0.30.
4. An unweighted average would give 0.16, a wrong objective when child sizes differ.

## Self-check

1. What is Gini for a balanced binary node?

Answer: 0.5.

2. Why weight child impurity?

Answer: The objective averages impurity over observations, so larger nodes contribute more.

3. Does deeper always generalize better?

Answer: No; it can reduce training error while increasing overfitting.

4. Why randomize candidate features?

Answer: To diversify trees and reduce correlated errors, subject to a strength-diversity tradeoff.

5. What is the mastery evidence?

Answer: A checked split calculation, depth experiment, and a forest comparison under one evaluation protocol.

## One-page recap

Trees trade a simple global equation for local rules. Ensembles reduce some instability but do not repair a flawed dataset or split.

Margin methods return to geometric boundaries and ask how far examples lie from them.

## Terms

- Gini impurity (基尼不纯度): One minus the sum of squared class proportions at a node.
- bagging (自助聚合): Combining predictors fitted on bootstrap samples.
- random forest (随机森林): An ensemble of randomized decision trees.
